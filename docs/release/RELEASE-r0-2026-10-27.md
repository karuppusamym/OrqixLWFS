## What is new since r0-2026-10-26

- **Studio:** BPMN notation shapes with a toggle and legend (cards remain), a conversational authoring panel on the left (validated edit operations; needs an AI key), a visible Test tab with integration mocks and assertions, BPMN 2.0 export with diagram interchange, and a read-only CMMN preview.
- **Waiting on outside systems:** callback tokens with a poll and resume API, signed inbound webhooks, outbound webhooks with retries and dead letters, and Kafka consumer triggers that start or resume a run.
- **Standards:** BPMN 2.0, CMMN 1.1 and DMN are followed for the admitted subsets; UML is not followed by design ([docs/25](../25-studio-and-integration-roadmap.md)).
- **User guide** sections for all of the above; the Cases notice is reworded.

## Upgrade notes

1. Back up first; rollback means restoring the backup. New migrations: `V160`, `V170` to `V172`. Do not edit released migrations, not even comments.
2. Kafka mode is **off** by default. Enabling it needs a broker and the new `kafka-clients` dependency (4.1.2; licences in [docs/07](../07-open-source-and-licensing.md) if present in your copy).
3. Webhook signatures use the `v1=` domain-separated form, and webhook secrets use the `webhook-` secret-reference namespace.
4. Test assertions are shared with the publish gate, so existing workflows with assertions are checked at publish.
5. New drafts default to the BPMN notation; the AI panel works only when an AI key is configured.
