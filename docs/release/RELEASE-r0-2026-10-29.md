## What changed since r0-2026-10-28

- **Insights at volume ([S102](../build/S102-insights-and-inbox-at-volume.md)):** finished figures are kept 30 seconds per replica and shared by concurrent viewers (`orqix.insights.cache-ttl-seconds`, 0 turns it off; access is still checked on every call). Inbox counts are exact up to 1,000. On 100,000 requests with 12 concurrent viewers: Insights 1.1 to 26 calls per second (median 2.5 s to 38 ms), claimable inbox 8.0 to 18.5 calls per second (median 648 to 245 ms).
- **Assistant:** a message that names a workflow ("I need a purchase") is matched by name at once, with no AI (25 s before on the demo); other wording asks the AI when a key is set, and when nothing fits the person is shown what they can start instead of an error.
- **Friendlier screens:** the Cases banner is gone (the limit is stated in the case form); "AI help is switched off here" is a calm note with what to do instead; **Home > Get started** cards for people who build workflows or set the workspace up.
- **Samples:** `tools/demo/seed_gallery.py` adds shared decision tables and eight example workflows; the new [what you can do](../what-you-can-do.md) guide maps every capability and its limits.
- Earlier in this release line (already pushed in r0-2026-10-28 or later fixes): Studio layout (View menu, Ask AI dock, cards), Ctrl+K, dictation messages.

## Upgrade notes

1. Back up first; no schema change.
2. Insights figures can be up to 30 seconds old by default; set `ORQIX_INSIGHTS_CACHE_TTL_SECONDS=0` for always-fresh figures at the cost of recomputing for every viewer.
3. The My tasks badge and tab counts stop at 1,000 (shown as `1000+`).
4. Everything in the earlier upgrade notes still applies.

## Known limits

Unchanged from r0-2026-10-28, plus: the request-number lock (one workspace starts requests one after another, about 14 per second per workflow) is **not** fixed: many readers use the reference inside the start transaction (S102). Bank-scale capacity is not proven. Still open: WM04 (full CMMN), UI02 (general application designer), real Pega Blueprint PDFs, production identity provider and high availability. One stale draft "Sample - Document review" from an earlier gallery run remains on the demo stack (it needs a Microsoft connection; workflows cannot be deleted from the API).
